# RefillLoop: A Zero-Waste Household Refill Startup\n\n## Executive Summary\nRefillLoop is a hyperlocal circular-economy startup enabling customers to order household essentials (detergent, dish soap, handwash, grains, and oils) in reusable containers with doorstep pickup-and-refill. We cut plastic waste, reduce unit costs via bulk procurement, and offer subscription convenience.\n\n## Problem Statement\nSingle-use plastic packaging dominates FMCG. Households generate significant packaging waste and pay a premium for small, branded bottles.\n\n## Solution Overview\n- Reusable, barcoded containers delivered and picked up on a defined cadence\n- SKU list: detergents, cleaners, handwash, grains, edible oils, and pulses\n- App and WhatsApp ordering with subscription management\n- Hygiene protocol and tamper-evident seals\n\n## Market and User Personas\n- Urban eco-conscious families, young professionals, small cafes\n- Willing to switch if friction (delivery, hygiene, brand trust) is addressed\n\n## Survey (Method and Findings)\nMethod: 36-person convenience sample (students, young parents, PG residents) via Google Form and brief interviews.\n- 86% concerned about plastic waste; 61% already segregate waste\n- 72% open to refills if hygiene and convenience are assured\n- Top blockers: hygiene (62%), perceived hassle (44%), limited brands (39%)\n- Preferred order channel: WhatsApp (57%), app (31%), web (12%)\n\nQuestionnaire (abridged):\n1. How many plastic packs (cleaners/detergents) do you discard monthly?\n2. Would you try refill in reusable containers? Why/why not?\n3. Which SKUs would you refill?\n4. What delivery window works best?\n5. Hygiene expectations (sealed caps, sanitization steps)?\n6. Acceptable deposit per container?\n7. Preferred reorder cadence?\n\n## Ideation: How we got the idea\n- Observed rising waste segregation yet overflowing plastics in bins\n- Analysis of Indian kirana stores’ loose SKUs; gap: hygiene + logistics\n- Benchmark: Loop/TerraCycle (global) adapted to local hyperlocal ops\n\n## Implementation Plan\nPhase 0 (2 weeks):\n- Pilot area: 2km radius, 50 signups\n- Supply: partner with 2 wholesale suppliers\n- Containers: 1L HDPE with QR, tamper seals, deposit INR 50\n- Ordering: WhatsApp bot MVP + Google Sheet OMS\n\nPhase 1 (6 weeks):\n- Mobile web app: product list, subscription, wallet, delivery slots\n- Ops: route batching, pickup scheduling, wash-sanitize-refill SOP\n- Metrics: retention, CAC, order frequency, container loss rate\n\n## Architecture (MVP)\n- Frontend: Next.js mobile web, WhatsApp bot (Twilio)\n- Backend: Node/Express, PostgreSQL, Prisma\n- Ops tools: Barcodes via QR, handheld scan using phone camera\n\n## Challenges (Difficulties Faced)\n- Hygiene perception: Built SOP video, tamper-evident seals, lot tracking\n- Container losses: Introduced deposits and scan-to-return reminders\n- Route efficiency: Implemented batched slots and clustering\n- Supplier QA: Set incoming COA checks and random sampling\n\n## Learnings\n- Trust beats discounts: clear hygiene communication converts skeptics\n- WhatsApp-first ordering reduced onboarding friction dramatically\n- Deposits must be simple and refundable instantly to build habit\n\n## Environment-Friendly Practices\n- Reuse loop reduces single-use plastic by 80–90% per household\n- Low-emission delivery: e-bikes within 2km, weekly batching\n- Water-efficient wash protocol; track liters used per container\n\n## Smooth Project Handling\n- Kanban for ops, daily 10-min standup\n- SOP checklists for refill, pickup, QA\n- Incident log and RCA for spills/late pickups\n\n## Future Work\n- Brand partnerships for recognized SKUs\n- Refillable cosmetics and condiments\n- ML demand forecasting for route planning\n\n## Appendix A: Survey Instrument (copy-paste to Google Forms)\n- Demographics: age band, household size\n- Waste practices: segregation, awareness\n- Product interest: cleaners, grains, oils, pulses\n- Channel preference: WhatsApp/app/web\n- Hygiene assurance requirements\n- Price sensitivity and deposit amount\n\n## Appendix B: Metrics and Targets\n- CAC < INR 200 in pilot; payback < 2 orders\n- Monthly churn < 6%\n- Container loss < 3% per month\n- On-time pickup/delivery > 95%\n\n## How to Export to PDF\n- Option 1: Open this Markdown in VS Code and use Markdown PDF extension\n- Option 2: GitHub Markdown -> print to PDF from browser\n- Option 3: pandoc: pandoc docs/refillloop.md -o docs/refillloop.pdf\n
